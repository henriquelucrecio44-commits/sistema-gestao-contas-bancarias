# Sistema de Gestão de Contas Bancárias

Projeto desenvolvido em C++ para a disciplina de programação.

## Etapa 1 – Implementação inicial

Desenvolvimento da primeira versão do sistema, com implementação das funcionalidades iniciais e utilização de variáveis para permitir o cadastro de até 5 contas bancárias.

## Etapa 2 – Estruturas de repetição

Aprimoramento do sistema utilizando as estruturas de repetição:

- while
- do-while
- for

Essas estruturas foram utilizadas para controlar o menu e executar as operações do sistema.

## Tecnologias utilizadas

- C++
- Visual Studio Code
- Git
- GitHub
